# Схема данных Divvy Tripdata

| Поле | Тип | Смысл | Nullable |
|---|---|---|---|
| `ride_id` | STRING | Уникальный анонимизированный идентификатор поездки | Нет |
| `started_at` | TIMESTAMP | Время начала поездки | Нет (отбраковывается при NULL) |
| `ended_at` | TIMESTAMP | Время окончания поездки | Нет (отбраковывается при NULL) |
| `start_station_name` | STRING | Название станции начала | Да |
| `end_station_name` | STRING | Название станции конца | Да |
| `member_casual` | STRING | Тип клиента: 'member' (подписчик) или 'casual' (разовый) | Да |
| `duration_sec` | INT | Расчетная длительность поездки в секундах | Нет |
| `year` | INT | Год поездки (для партиционирования) | Нет |
| `month` | INT | Месяц поездки (для партиционирования) | Нет |
